# AppleTvControlLibrary Documentation

API documentation for the Apple TV Companion Link protocol and discovery libraries.

- [API reference](api/toc.html)
- [Repository README](https://github.com/oznetmaster/AppleTVControlLibrary#readme)
- [NuGet packages](https://www.nuget.org/profiles/oznetmaster)

`AppleTvControlLibrary` and `AppleTvControlLibrary.Discovery` are independent libraries.
Install `AppleTvControlLibrary.All` to restore both packages together.
